# Attack Path Risk Engine

An extension of [Cartography](https://github.com/cartography-cncf/cartography) that automatically
discovers multi-hop cloud attack paths and scores them by risk.

Final-year capstone project — AMET University, Dept. of CSE (Cybersecurity).
