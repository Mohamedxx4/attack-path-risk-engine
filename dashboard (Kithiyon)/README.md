# Dashboard

Layer 3 of the Attack Path Risk Engine.

Owner: Kithiyon

## What this does

Consumes ranked output from `/risk-scoring` and displays each path as a
plain-language finding, e.g.:

    "Public Web Server → Admin Role → Production S3 Bucket — Risk: HIGH"

Includes a graph view of the selected path, rendered node by node.
